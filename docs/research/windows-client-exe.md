# ملاحظات البحث — عميل NetRouter Manager بصيغة Windows EXE

لتحقيق مطلب برنامج إدارة مستقل بلا متصفح، سيُبنى عميل NetRouter Manager كبرنامج سطح مكتب Go منفصل عن صورة NetRouter OS. تم اختيار Fyne كبداية عملية للنسخة 0.1 لأنه يوفر واجهة سطح مكتب متعددة المنصات من قاعدة Go واحدة، ولا يحتاج المستخدم النهائي إلى تثبيت أدوات تطوير أو اعتماديات وقت التشغيل بحسب توثيقه الرسمي. [1]

يتطلب تطوير Fyne أدوات Go ومترجم C وبرنامج تشغيل رسوميات على جهاز التطوير. ولإخراج ملف Windows x86_64 من لينكس، يوضح التوثيق أن التجميع المتقاطع يتطلب `CGO_ENABLED=1` ومترجم C للهدف مثل `x86_64-w64-mingw64-gcc`، أو يمكن استعمال بيئة تجميع تحتوي MinGW. [2]

| قرار | تطبيق في الإصدار 0.1 | نتيجة عملية |
| --- | --- | --- |
| شكل العميل | برنامج Windows مستقل `NetRouterManager.exe` | يفصل الإدارة عن الراوتر ولا يعتمد على المتصفح. |
| لغة الواجهة | Go مع Fyne | تبقى طبقات النموذج وبروتوكول الإدارة مشتركة مع النظام عند الإمكان. |
| بناء Windows | x86_64 Windows أولاً | يطابق معمارية جهاز الإدارة الأكثر شيوعاً في المرحلة الأولى. |
| توزيع لاحق | حزمة موقعة ومثبت Windows | لا يُعلن التوقيع أو التوزيع الإنتاجي قبل إضافة مفاتيح الإفراج وإجراء اختبار جهاز Windows حقيقي. |
